# Исследование подходов к транскрибации голосовых сообщений

## Обзор

Для добавления транскрибации голосовых сообщений в Telegram-бота существует несколько подходов. Ниже представлен анализ различных решений с учетом требований проекта.

## 1. Облачные API

### 1.1. OpenAI Whisper API

**Описание:** Облачный API от OpenAI на базе модели Whisper для распознавания речи.

**Плюсы:**
- ✅ Высокое качество распознавания (особенно для русского языка)
- ✅ Простая интеграция через OpenAI Python SDK
- ✅ Поддержка множества языков (включая русский)
- ✅ Хорошая обработка акцентов и фонового шума
- ✅ Единый интерфейс с другими OpenAI API (уже используется в проекте)

**Минусы:**
- ❌ Платный сервис ($0.006 за минуту)
- ❌ Требует интернет-соединение
- ❌ Задержка из-за сетевых запросов

**Сложность интеграции:** ⭐⭐ (Низкая)
- Уже используется `openai` библиотека
- Простой вызов `openai.Audio.transcribe()`

**Производительность:** Высокая (обработка на серверах OpenAI)

**Стоимость:** $0.006 за минуту аудио (~$0.36 за час)

---

### 1.2. Yandex SpeechKit

**Описание:** Облачный сервис от Яндекса для распознавания речи.

**Плюсы:**
- ✅ Отличное качество для русского языка
- ✅ Бесплатный тариф (до 20 часов в месяц)
- ✅ Низкая задержка для российских пользователей
- ✅ Поддержка длинных аудио

**Минусы:**
- ❌ Требует регистрацию в Yandex Cloud
- ❌ Дополнительная зависимость (yandex-speechkit-sdk)
- ❌ Ограничения бесплатного тарифа

**Сложность интеграции:** ⭐⭐⭐ (Средняя)
- Требует настройку Yandex Cloud аккаунта
- Необходимо получить API ключ

**Производительность:** Высокая

**Стоимость:** Бесплатно до 20 часов/месяц, далее ~₽0.5 за минуту

---

### 1.3. AssemblyAI

**Описание:** Облачный API для транскрибации с дополнительными возможностями.

**Плюсы:**
- ✅ Высокое качество
- ✅ Дополнительные функции (детекция говорящих, пунктуация)
- ✅ Хорошая документация

**Минусы:**
- ❌ Платный сервис
- ❌ Менее популярен в России
- ❌ Дополнительная зависимость

**Сложность интеграции:** ⭐⭐⭐ (Средняя)

**Производительность:** Высокая

**Стоимость:** $0.00025 за секунду (~$0.90 за час)

---

## 2. Локальные решения

### 2.1. Whisper локально (OpenAI Whisper)

**Описание:** Модель Whisper, запущенная локально через библиотеку `whisper` или `faster-whisper`.

**Плюсы:**
- ✅ Бесплатно (после установки)
- ✅ Работает офлайн
- ✅ Высокое качество распознавания
- ✅ Полный контроль над данными

**Минусы:**
- ❌ Требует значительные ресурсы (GPU рекомендуется)
- ❌ Медленная обработка на CPU
- ❌ Большой размер модели (~1.5GB для base модели)
- ❌ Дополнительные зависимости (ffmpeg, pytorch)

**Сложность интеграции:** ⭐⭐⭐⭐ (Высокая)
- Требует установку Whisper и зависимостей
- Необходима конвертация аудио форматов
- Требует GPU для приемлемой скорости

**Производительность:** Средняя на CPU, высокая на GPU

**Стоимость:** Бесплатно (но требует вычислительные ресурсы)

---

### 2.2. Vosk

**Описание:** Легковесная библиотека для офлайн распознавания речи.

**Плюсы:**
- ✅ Очень быстрая работа
- ✅ Легковесная модель (~50MB для русского)
- ✅ Работает офлайн
- ✅ Хорошая поддержка русского языка

**Минусы:**
- ❌ Качество ниже, чем у Whisper
- ❌ Менее точное распознавание в шумной среде
- ❌ Требует предобработку аудио

**Сложность интеграции:** ⭐⭐⭐ (Средняя)

**Производительность:** Очень высокая

**Стоимость:** Бесплатно

---

## 3. Мультимодальные модели Speech-to-Text

### 3.1. Ollama с Whisper моделью

**Описание:** Использование Whisper через Ollama (если настроен локальный сервер).

**Плюсы:**
- ✅ Единый интерфейс с другими моделями
- ✅ Использование существующей инфраструктуры
- ✅ Бесплатно (если Ollama на своем сервере)

**Минусы:**
- ❌ Требует настройку Ollama сервера
- ❌ Зависит от доступности сервера

**Сложность интеграции:** ⭐⭐⭐ (Средняя)

**Производительность:** Зависит от сервера

**Стоимость:** Бесплатно (если свой сервер)

---

## 4. Telegram Bot API возможности

**Описание:** Telegram Bot API не предоставляет встроенной транскрибации, но позволяет получать голосовые сообщения.

**Особенности:**
- Telegram хранит голосовые сообщения в формате OGG Opus
- Необходима конвертация в формат, поддерживаемый API транскрибации
- Можно использовать `ffmpeg` для конвертации

## 5. Рекомендация для проекта

### Выбранный подход: **Yandex SpeechKit** (основной провайдер)

**Обоснование выбора:**

1. **Региональные ограничения** ⚠️
   - OpenAI Whisper API недоступен из-за региональной блокировки
   - Регистрация в OpenAI не проходит даже с VPN
   - Yandex SpeechKit доступен для российских пользователей

2. **Качество распознавания** ⭐⭐⭐⭐⭐
   - Отличное качество для русского языка (специализация Yandex)
   - Хорошая обработка акцентов и фонового шума
   - Поддержка длинных аудио

3. **Стоимость** ⭐⭐⭐⭐⭐
   - Бесплатный тариф до 20 часов/месяц
   - Для личного проекта - более чем достаточно
   - После лимита: ~₽0.5 за минуту (приемлемо)

4. **Простота интеграции** ⭐⭐⭐
   - Простой REST API через `aiohttp`
   - Требует настройку Yandex Cloud (получение API ключа)
   - Средняя сложность настройки прав доступа

5. **Производительность** ⭐⭐⭐⭐
   - Низкая задержка для российских пользователей
   - Быстрая обработка на серверах Yandex

### Альтернативный подход: **OpenAI Whisper API** (когда будет доступен)

**Преимущества:**
- Высокое качество распознавания (одна из лучших моделей)
- Простая интеграция (уже используется `openai` библиотека)
- Единый интерфейс с другими OpenAI API

**Недостатки:**
- ❌ Недоступен из-за региональной блокировки
- Платный сервис ($0.006 за минуту)

**Статус:** Код реализован и готов к использованию, но провайдер недоступен в текущем регионе.

### Альтернативный подход (если нужна приватность): **Whisper локально**

- Требует GPU для приемлемой скорости
- Можно использовать через Ollama, если сервер настроен
- Полный контроль над данными
- Требует дополнительную инфраструктуру
