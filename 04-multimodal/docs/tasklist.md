- [ ] Обновить `src/config.py`: добавить SYSTEM_PROMPT_TEXT

  - Обновить `/start`: очистка истории и транзакций для пользователя
  - Добавить логирование ответов LLM (содержимое ответа + извлеченные транзакции)
- [ ] Добавить зависимость `pydantic` в `pyproject.toml`

**Как протестировать:**

**Выбранный подход:**
- **Основной провайдер**: Yandex SpeechKit (оптимален для русского языка, бесплатный тариф до 20ч/месяц)
- **Альтернативный провайдер**: OpenAI Whisper API (высокое качество, но недоступен из-за региональных ограничений)

**Статус реализации:**

- ✅ Поддерживает переключение между провайдерами через конфигурацию

**Выполненные задачи:**

- [x] Обновить `docs/vision.md` - добавить поток данных для голосовых сообщений
- [x] Добавить итерацию 6 в `docs/tasklist.md`

  - `transcribe_voice_openai()` - для OpenAI Whisper API

  - `transcribe_voice()` - универсальный метод с выбором провайдера

  - Конвертация формата (OGG Opus → формат для выбранного API)
  - Транскрибация через `transcription.py`
  - Передача текста в существующий обработчик текстовых сообщений
  - Показ транскрибированного текста пользователю
- [x] Добавить обработку ошибок транскрибации (включая специальную обработку ошибок Yandex Cloud)
- [x] Добавить логирование транскрибации
- [x] Добавить конфигурацию провайдера через `TRANSCRIPTION_PROVIDER` в `.env`
- [x] Реализовать graceful degradation: бот продолжает работать с текстом и изображениями при недоступности транскрибации

**Как включить транскрибацию:**
1. **Для Yandex SpeechKit:**
   - Настроить права доступа в Yandex Cloud (роли `ai.speechkit-stt.user` и `editor` на уровне каталога)
   - Добавить в `.env`:
     ```
     TRANSCRIPTION_PROVIDER=yandex
     YANDEX_SPEECHKIT_API_KEY=ваш_ключ
     YANDEX_SPEECHKIT_FOLDER_ID=ваш_folder_id
     ```
   - Убрать ранний `return` в `handle_voice()` в `src/handlers.py`

2. **Для OpenAI Whisper (если будет доступен):**
   - Получить API ключ от OpenAI (не от OpenRouter)
   - Добавить в `.env`:
     ```
     TRANSCRIPTION_PROVIDER=openai
     WHISPER_API_KEY=sk-proj-... (ключ от OpenAI)
     ```
   - Убрать ранний `return` в `handle_voice()` в `src/handlers.py`

**Как протестировать (после включения):**
- Отправить голосовое сообщение в Telegram с описанием транзакции (например: "Сегодня купил продукты на 1500 рублей")
